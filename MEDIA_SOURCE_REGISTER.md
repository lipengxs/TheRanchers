# The Ranchers media source register

Last reviewed: 2026-08-03  
Publisher: The Ranchers Independent Fan Guide

## Rule for the four status pages

`/release-date`, `/platforms`, `/steam-price-and-availability` and `/multiplayer-guide` currently use CSS-only neutral information visuals. They use no game screenshot, video thumbnail, gameplay clip or generated game artwork.

Before an official media item is added to one of these pages, record the following fields here: source URL, publisher/channel, original publication date where shown, access date, page where used, purpose, attribution/copyright note, and the condition that requires replacement or removal.

## Approved media records

No external game media is currently approved for the four status pages.

## Candidate official sources — not approved media records

| Source | Allowed future use after capture and review | Current status |
| --- | --- | --- |
| https://ranchers.game/ | Official media explicitly published on the developer site | Needs item-level source capture |
| https://store.steampowered.com/app/1501310/The_Ranchers/ | Store assets only where their current display and use are verified | Needs item-level source capture |
| https://www.youtube.com/@RanchersGame | Official video thumbnails or links, with title and publication record | Needs item-level source capture |

Generated neutral infographics must not depict game characters, maps, products, price labels, platform availability, or official logos. They do not require an external source record, but their purpose must remain explanatory rather than promotional.
