First-day route

The highest-value first session is not a perfect farm. It is a stable loop: finish the introduction, note the map exits, test one vehicle route, and record which animal, crop, or crafting systems are actually unlocked in the Early Access build.

  • Start with tutorials and save behavior.
  • Check co-op invite flow before planning a shared ranch.
  • Link discoveries back to animals, vehicles, and wiki pages.

Demo save carry-over

Do not promise save transfer unless the developer or store page confirms it. If the demo remains separate, frame the demo as route practice and UI familiarity rather than progress that will automatically survive launch.
